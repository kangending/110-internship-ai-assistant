# 页面与状态清单

> 项目：110线上考试——AI 求职准备助手  
> 产品形态：Desktop Web  
> 主要演示尺寸：1440 × 900  
> 主要使用角色：首次准备实习、已有明确目标岗位的大学生  
> 演示案例：林浩（虚构模拟案例）  
---

## 1. 编号说明

- `P01～P08`：核心流程页面。
- `A / B / C...`：同一页面下的不同关键状态。
- `D`：Drawer / 抽屉。
- `M`：Modal / Dialog / 弹窗。
- `S`：跨页面的处理中、失败、演示模式等全局状态。
---

# 2. 产品核心流程

当前可操作原型主要覆盖以下流程：

**P01 首页**  
→ **P02 建立诊断**  
→ **S01 AI 分析处理中**  
→ **P03 AI 理解确认**  
→ 补充 / 确认 / 纠正  
→ **S03 纠正后重新分析**  
→ **P04 我的诊断**  
→ 查看建议依据 / 变化记录 / 信息不足状态  
→ **P05 行动选择**  
→ Java 可执行方案或 Direction 诊断完成  
→ **P06 当前行动**  
→ 周期结束  
→ **P07 行动反馈**  
→ **S04 行动反馈更新中**  
→ **P08 本次更新结果**

异常和辅助流程还包括：

- **S02 AI 生成失败**
- **S05 演示模式菜单**
- 标准演示路径
- Direction 完成态
- 体验完整模拟闭环
- 输入校验
- 纠错与修改
- 完成弹窗

# 14. S02 AI 生成失败

| 编号 | 名称 | 使用角色 | 进入方式 | 主要操作 | 去向 | 对应原型位置 |
|---|---|---|---|---|---|---|
| S02 | 模拟 AI 生成失败 | 求职学生 / 评审 | 通过演示模式触发受控失败状态 | 重新生成；返回修改信息 | 正常分析流程 / P02 | `S02_AI生成失败.png` |

### 说明

当前原型未接入真实 AI 服务，因此 AI 生成失败采用受控 Mock 方式展示。该状态用于验证：

- 失败信息是否明确；
- 用户输入是否保留；
- 是否可以重新生成；
- 是否可以返回修改；
- 失败后不会伪造正常结果。
