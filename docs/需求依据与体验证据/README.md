
# 需求依据与体验证据

本目录用于保存“面向首次准备实习大学生的 AI 求职准备助手”在需求判断阶段使用的真实体验材料。

本目录中的内容主要用于回答：

> 当前用户已经可以通过什么方式解决“岗位差距判断与下一步行动”问题？现有方式在哪些地方已经做得较好，又有哪些体验仍值得进一步产品化？

---

## 1. 证据来源

本次实际体验对象包括：

### ChatGPT

使用虚构用户“林浩”和统一的 Java 后端开发实习生 JD，实际完成：

- 岗位要求理解；
- 用户经历输入；
- 岗位差距分析；
- 用户纠正；
- 建议重新排序；
- 7天行动计划。

### 牛客 AI 岗位辅导师

使用相同的目标岗位和尽可能一致的用户信息，实际完成：

- JD分析；
- 简历/经历匹配分析；
- 用户信息纠正；
- 优先级调整；
- 7天行动计划。

---

## 2. 测试原则

为提高两次体验的可比性，本次尽量保持以下条件一致：

- 使用同一个虚构用户“林浩”；
- 使用同一份目标岗位 JD；
- 使用相同的初始能力描述；
- 使用相同的项目经历；
- 使用相同的用户纠正信息；
- 最后均要求 AI 只制定未来7天最值得做的行动。

本次体验不是严格的实验研究，仅用于产品设计阶段的替代方案体验和需求判断。

---

## 3. 证据类型说明

本项目严格区分：

### 实际观察

指本次亲自操作产品后真实看到的：

- 页面；
- 交互；
- AI回答；
- 功能；
- 状态。

### 个人体验判断

例如：

- 入口不容易发现；
- 长文本阅读成本较高；
- 聊天式结果回看不方便。

这些属于本次设计者的体验判断，不代表所有用户。

### 待验证产品假设

例如：

- 将事实、推测和未知信息拆分后，用户会更容易理解 AI；
- 将建议转化为独立行动状态后，用户更容易持续执行；
- 建议变化可视化后，用户更容易理解 AI 为什么改变建议。

这些内容目前尚未通过真人测试验证，不作为事实结论。
