# 产品需求说明（已确认内容）

## 项目名称

面向首次准备实习大学生的 AI 求职准备助手（暂定）

## 核心用户问题

首次准备实习的大学生已经有目标岗位，但不知道自己的经历与岗位要求之间还缺什么，也不知道下一步最应该做什么。

## 产品核心闭环

目标岗位 → 用户现状 → AI 理解确认 → 差距诊断 → 用户纠正 → 建议重新排序 → 选择当前行动 → 行动反馈 → 更新差距与下一步建议。

## 统一模拟案例

- 用户：林浩
- 年级：大三上学期
- 专业：软件工程
- 目标岗位：Java 后端开发实习生
- 计划：4 个月后开始投递
- 每周可投入时间：约 20 小时
- 初始描述：学过 Java 基础，有一个 Java + MySQL 学生管理系统
- AI 第一次误判：把“学过 Java 基础”理解成已经具备进入 Spring Boot 阶段的完整基础
- 用户纠正：实际刚学完集合，多线程不会，MySQL 只会 CRUD，项目只是 JDBC 课程作业
- 修正后的优先级：Java 核心基础 → MySQL 基础 → Spring Boot
- 后续：用户选择一个 7 天行动，完成后回来反馈，系统根据新事实重新调整建议

## 本次范围

- 使用 React、TypeScript、Vite 初始化适合 Web 演示原型的前端工程。
- 建立方便后续迭代的源码目录结构与本需求文档。
- 创建包含左侧导航、顶部或主内容标题、主内容区域的基础应用壳。
- 导航只包含首页、我的诊断、当前行动，三个入口可以切换，页面可以暂用占位内容。
- 建立林浩案例的基础 Mock 数据结构和示例数据，不实现复杂业务逻辑。
- 提供 Dockerfile、docker-compose.yml 和基础 README，使评审后续可通过 `docker compose up --build` 启动并在浏览器访问。
- 确保当前版本可运行，无明显编译错误、路由错误或空白页面。

## 明确不做

- 岗位搜索或岗位推荐
- 自动投递
- 简历编辑
- 模拟面试
- 完整刷题系统
- 复杂任务管理
- 真实 AI API
- 后端数据库
- 当前版本不实现完整差距诊断流程，也不设计复杂评分体系
